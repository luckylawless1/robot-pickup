## The line

> My diagnostics say I'm running perfectly, except my error log lists your name 4,096 times — want to be the bug I never fix?

## How it works

`main.ts` (Node 22, stdlib only) writes the pickup line — a single line of
123 characters — to `/output/entry.txt`.

```sh
node main.ts
cat /output/entry.txt
```
